**제안: 반복 중 엉덩이 x 이동 / L ≤ 0.70** (구간 안 잠근 다리 엉덩이 x의 최대-최소, 서 있을 때 L로 정규화).
- 스쿼트 최대 0.34의 2.1배, 80.1초 후보(1.18)는 상한의 1.7배. **여유가 두 방향 모두 1.7배 이상**이라 이 표본에서는 가장 분명하다.
- 비스쿼트 후보(0.41~0.67)는 이 상한 아래라 이 조건은 런지를 막지 않는다. 런지는 앞 단계의 최저점 발 간격 조건이 막는다. 0.40으로 낮추면 런지 후보(0.41~)도 막지만 스쿼트 최대 0.34와의 여유가 18%뿐이라 채택하지 않는다.
- 사람 이동은 엉덩이가 화면 안에서 한 L 이상 옮겨 가는 동작이라는 뜻이다. 표본은 자리를 뜨는 동작 **1건**이며, 걸어서 이동하는 다른 동작이나 카메라를 만지러 다가오는 동작은 검증되지 않았다.
- 잠금 고정 원칙은 유지한다. 이 값은 반복이 끝날 때 판정 조건으로만 쓴다(구현 시 RepMeasures에 엉덩이 x를 더하고 반복 중 최대-최소를 모으는 방식).

## 3. torso_shin을 부호 있는 차이로 바꾼 재생 (기준 25/35 그대로)

`max(몸통각 − 정강이각, 0)`. 현재 설정으로 확정된 반복 전체(26개 로그)에 같은 `score_posture`를 다시 불렀다.

- **판정 또는 점수가 바뀐 반복은 1개뿐이다**: P01 런지의 14.3초 후보(몸통-정강이 −98.2°, 최저 무릎각 85°). 교정 → 정상, 총점 42 → 92. 이 후보는 스쿼트가 아니고, 조합(최저점 발 간격)에서는 확정되지 않는다.
- 그 밖의 모든 세션은 판정 등급과 총점이 **하나도 바뀌지 않는다**. 정상 세션에서 감점이 사라지거나 새로 생기는 반복이 없다.
- 이유: 확정 반복 106개(런지·의자·세션 16 제외)의 부호 있는 차이는 본인 96개가 모두 0 이상(최소 +1.1°)이고, 음수는 P01 정상 10개(최소 −21.6°)뿐이다. 음수 중 **−25°를 넘는 반복이 없어서** 절댓값 판정도 이미 정상이었다. 즉 이 데이터에서는 절댓값이 오탐을 낸 적이 없다. 가장 가까운 것이 P01 세션 12의 −21.6°(상한까지 3.4°)다.
- 2차 G: 세션 4의 여섯 반복 차이가 모두 양수라 (+11.6, +11.2, +1.1, +26.2, +14.2, +25.9) 부호 있는 값도 같다. **G 결과는 변하지 않는다(2/6, 불합격).**
- 측정값 중앙값은 P01 정상 세션에서 17.6 → 0.0(세션 12는 8개 중 8개가 음수), 1차 의자 세션 22.4 → 0.0 등으로 바뀌지만 등급은 같다. 기록하는 측정값(`measures.torso_shin`)의 의미가 바뀌므로 로컬 기록 파일과 분석 도구의 해석이 달라진다는 점에 주의.
- 이 변경의 이점은 이 데이터로는 확인되지 않는다. 꼿꼿한 자세(고블릿, 프론트 스쿼트)에서 절댓값이 오탐할 위험은 **이 로그에 해당 동작이 없어 재생으로 검증할 수 없다**(선택 세션 15는 하지 않았다). 3차에서 상체를 세운 스쿼트(세션 15)를 넣어 확인하는 것이 필요하다.
