# Phase 5(릴리스) 체크리스트

릴리스 전에 확인할 것을 모은 목록이다. DEVLOG에 흩어져 있던 항목을 모았고, 완료하면 체크한다. (이 문서는 2026-10-19에 만들었고 2026-10-20에 2차·3차 실측, 본인 연속 세트 확인, 플래그 제거, 문서·버전 작업 결과에 맞게 다시 갱신했다.)

**현재 상태(2026-10-20)**: 실측과 코드 정리는 끝났다(이후 다른 참여자의 실측은 하지 않는다). 연속 세트(B)는 본인 재확인에서 합격했고 기본 꺼짐 플래그 4개를 제거했다. **A~C단계(실측 정리, 코드·설정, 문서·버전)는 끝났고, D단계(설치판)부터는 사용자 확인 뒤에 진행한다.** Phase 5로 진행하는 것은 3차 결과를 본 뒤의 사용자 결정(규칙 예외, 프로토콜 11.2절)이다.
